# 网站盒子

一个可以直接打开的本地收藏网页，用于整理好用的网站、喜欢的图片和想看的影视资源。无需安装依赖，也无需联网，数据保存在当前浏览器中。

## 运行方式

双击 `index.html` 即可使用。也可以把这个文件夹放到任意静态服务器上访问。

## 功能

- 三个资料库：网站收藏、优美图片、影视收藏
- 添加、编辑、删除、置顶收藏
- 按分类或标签筛选，支持关键词搜索
- 图片和影视封面可点击放大查看
- 自动为缺封面的影视生成占位封面
- 导出 JSON 备份，支持导入恢复
- 首次打开会载入示例数据，可随时清空重建

## 数据说明

收藏数据保存在浏览器 `localStorage` 中，换浏览器或清除浏览器数据会丢失。建议定期点击右上角“导出备份”，把 JSON 文件单独保存；需要恢复时点击“导入备份”并选择该文件。

## 文件结构

```text
website-box/
├── index.html
├── css/styles.css
├── js/
│   ├── data.js      # 示例数据和默认占位封面
│   └── app.js       # 页面交互与本地存储逻辑
└── assets/
    ├── art/         # 示例图片
    └── posters/     # 影视默认封面
```

## 可选升级方向

- 换成 Python、Node.js 或云数据库做多端同步
- 使用浏览器的文件访问能力导入本地图片
- 增加标签云、月度回顾、随机推荐等展示视图
